# Aveds-test

🛠 Технологии
React/Vue + TypeScript
MSW для имитации API (вместо хардкода в коде)
React Router / Vue Router
CSS Modules / SCSS

📄 Страницы
Главная (/)
Личный кабинет (/profile) - только для авторизованных
Контакты (/contact)

⚙️ Функционал
Авторизация
На главной странице кнопка "Войти"
По клику → модальное окно с формой:
Логин (минимум 3 символа)
Пароль (минимум 8 символов)
Чекбокс "Запомнить меня"
Mock API с MSW
❗ Пароли НЕ хранить в коде! Использовать простую проверку через MSW.
Безопасность
Токен в localStorage / sessionStorage
Защита роутов (редирект без авторизации)
Очистка токена при выходе
Личный кабинет
Имя пользователя
Кнопка "Выйти"

🎨 Адаптивность
Desktop, Tablet (768px), Mobile (375px)
Допуск: 3-5px от макета

🎨 Модальное окно авторизации
Это основной элемент для оценки ваших UI/UX навыков.
Обязательные элементы:
Затемнение фона (overlay с opacity)
Центрирование модалки на всех устройствах
Плавная анимация появления (fade-in + scale)
Кнопка закрытия (крестик справа вверху)
Закрытие по клику вне модалки или по Escape

✅ Валидация в реальном времени (onChange или onBlur)
✅ Визуальные состояния полей:
Default (серая рамка)
Focus (синяя/акцентная рамка + тень)
Error (красная рамка + текст ошибки)
Success (зеленая рамка, опционально)
✅ Показать/скрыть пароль (иконка глаза)
✅ Disabled состояние кнопки "Войти" при невалидной форме
✅ Loading состояние при отправке (спиннер + disabled)
✅ Уведомление об ошибке ("Неверный логин или пароль")

## Инструкция по установке и запуску

📦Скопируйте этот репозиторий. Вам понадобятся "node" и "yarn", установленные глобально на вашем компьютере.  
Для установки node: посетите https://nodejs.org/en и скачайте установочный файл под свою OS  
Для установки yarn: введите в свой терминал `npm install -g yarn`

```bash
$ git clone git@github.com:EvilSoftWare-K-S/Aveds-test.git
$ cd Aveds-test
$ yarn install
$ yarn dev
```

Открой http://localhost:5173/ в своём браузере.

## gitflow

Ветвимся от test

Ветки называются по номеру задачи за исключением main и test
FAT-X, где X номер задачи.

Выполненные задачи пушим в test.

Коммиты оставляются по принципу:
'<feat>' - новый функционал/компонент/стиль
'<fix>' - исправлен баг
'<refactor>' - исправлен баг

## gitflow пример

git commit -m '<feat>:<Добавлен Header>'

To Run Linter:

```bash
yarn lint
```

To Build Project:

```bash
yarn build
```
